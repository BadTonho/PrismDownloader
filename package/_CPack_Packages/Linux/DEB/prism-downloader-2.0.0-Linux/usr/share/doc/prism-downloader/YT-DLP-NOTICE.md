# yt-dlp incluído no Prism Downloader

Este pacote distribui o executável oficial **yt-dlp Nightly** para permitir que
o Prism Downloader funcione imediatamente após a instalação.

- Projeto: https://github.com/yt-dlp/yt-dlp
- Canal incluído: Nightly
- Arquivo de versão, checksums e código-fonte: página oficial de releases do
  projeto yt-dlp.

O projeto yt-dlp é licenciado sob a Unlicense. Os executáveis standalone podem
conter componentes de terceiros, incluindo componentes GPLv3+. Consulte o
arquivo `THIRD_PARTY_LICENSES.txt` e as licenças publicadas pelo projeto yt-dlp
para a versão exata distribuída.
